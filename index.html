Interests

Set your Sim's interest level (0–10) in each topic. They're in the same order as the in-game interests panel.

Tip: with the game's default interests, Sims of the same age end up with similar results. The Interest Ages mod by rio-sims makes interests random, so the calculator gives more varied careers and hobbies.
